## 前言

xxB大模型，采用Adam BF16，需要多少G的显存

## 一、解释

这个是面试常问

计算链路：
**参数个数 × 每个数的字节数 → 参数显存**

\[ \boxed{ \text{训练峰值显存} = \text{各份参数相关张量的字节数之和} + \text{激活} + \text{临时开销} } \]

```
区分一个点：大模型的1B指的是Billion，1GB的是2的30次方字节

一般计算不严格的话，1B参数 x 4 Byte ≈ 4GB，但是严格换算为2进制的话，大概只有3.73GB
```

2B 模型”指大约有 **20 亿个这样的数**，并没有说明每个数用多少空间保存

| 保存格式    | 每个数占多少空间 |
| ----------- | ---------------- |
| FP32        | 32 bit = 4 byte  |
| BF16 / FP16 | 16 bit = 2 byte  |

所以，**只存权重**时：

\[ \text{显存}=\text{参数个数}\times\text{每个参数的字节数} \]

你的 2B 模型，权重全部用 BF16 保存：

\[ 2\times10^9\times2=4\times10^9\text{ byte}=4\text{ GB} \]

## 二、以线性函数举例

假设模型特别简单：

\[ y=wx \]

只有一个需要学习的参数 \(w=0.5\)。输入 \(x=2\)，希望输出接近目标 \(t=0\)。

前向计算得到：

\[ y=0.5\times2=1 \]

损失取：

\[ L=\frac12(y-t)^2=\frac12 \]

这时候，训练程序需要判断：**怎样改变 \(w\)，才能让损失下降？**

反向传播算出梯度：

\[ g=\frac{\partial L}{\partial w}=(y-t)x=2 \]

现在需要保存两个数：

| 数         | 例子 | 用途                 |
| ---------- | ---- | -------------------- |
| 参数 \(w\) | 0.5  | 当前模型的权重       |
| 梯度 \(g\) | 2    | 用来计算怎样更新权重 |

如果用普通 SGD，学习率为 \(0.01\)，更新就是：

\[ w_{\text{新}}=w_{\text{旧}}-0.01g=0.48 \]

因此，**一个可训练参数，对应一个梯度值。**

放大到 20 亿个参数，就对应 20 亿个梯度值。

## 三、对于Adam

记住需要保存两个数就可以了

- \(m\)：梯度的指数移动平均，反映最近的更新方向。

-  \(v\)：梯度平方的指数移动平均，用来调整更新步幅。

这两个m，v我目前还记不住，adam的公式也比较复杂，我直接跳过了

**只需要记住**：

一个普通的Ada在训练的时候，主要对应四个数

| 保存内容       | 数的个数 |
| -------------- | -------- |
| 权重 \(w\)     | 1        |
| 梯度 \(g\)     | 1        |
| 一阶动量 \(m\) | 1        |
| 二阶动量 \(v\) | 1        |
| **合计**       | **4**    |

## 五、激活函数

训练刚才的 \(y=wx\)，反向传播需要用到输入 \(x\)。复杂模型里也是如此：前向会产生许多中间结果，反向需要保存或重新计算它们，这部分通常称为激活。

比如，一个形状为：

\[ [\text{batch},\text{序列长度},\text{隐藏维度}] =[1,2048,2048] \]

的 BF16 中间张量，占用：

\[ 1\times2048\times2048\times2 \approx8.4\text{ MB} \]

计算过程：

张量有1x2048x2048这么多数，BF16对应16bit，因此最后还需要乘以2

这只是**一个张量**。模型有许多层，每层也可能保存多个张量，实际占用还取决于算子的实现。

## 总结

还是比较easy的，bf16，fp32，然后再看有多少个数，看使用的什么优化就行了，除开含参的相关状态，实际训练还要加上激活及临时开销，取决于每卡 batch、序列长度和训练实现。
